Web Server using Docker

This page is served by Nginx running inside a Docker container as a non-root user.

Checking server health…

Image

Built from nginxinc/nginx-unprivileged:1.28-alpine with a custom server block and the site files copied in at build time.

Health check

Docker calls /health every 15 seconds. Three failed checks in a row mark the container as unhealthy.

Hardening

Runs as UID 101 with a read-only root filesystem, all Linux capabilities dropped and no-new-privileges set.

Lifecycle

Build, run, stop, start, restart, inspect and remove the container with scripts/manage.sh or Docker Compose.
